# Agent Scheduler Neo

Ставит задачи `txt2img` и `img2img` в очередь в Forge Neo, захватывает актуальное состояние UI по `Enqueue` и позволяет отслеживать прогресс, историю и результаты через интерфейс планировщика.

English: [README.md](./README.md)

## Возможности

- Добавляет очередь задач для `txt2img` и `img2img`, а также историю и API-методы.
- Использует мост Enqueue для Gradio 4: по нажатию `Enqueue` собирает актуальные аргументы UI и отправляет их на `/agent-scheduler/v1/queue/ui`.
- Захватывает или инъецирует runtime-данные для ControlNet, ADetailer и TIPO, чтобы задача в очереди соответствовала текущему состоянию интерфейса.
- Извлекает generation info из результатов Forge Neo и использует PNG metadata как запасной вариант.
- Применяет совместимость с NeverOOM / inference-tensor внутри расширения через `agent_scheduler/forge_neveroom_compat.py`.
- Показывает прогресс и изображения для текущей выполняемой задачи.
- Сохраняет состояние таблицы очереди в `localStorage`.
- Поддерживает хоткей Enqueue и связанные действия в интерфейсе очереди.

## Установка

1. Поместите эту папку в `extensions/` Forge Neo.
2. После установки или обновления полностью перезапустите WebUI.
3. При первом запуске `install.py` установит `sqlalchemy`, если его нет.

## Использование

1. Настройте промпты и связанные скрипты, например ControlNet, ADetailer или TIPO.
2. Нажмите `Enqueue` вместо `Generate`, чтобы добавить текущую конфигурацию в очередь.
3. Откройте интерфейс или вкладку Agent Scheduler, чтобы следить за очередью, прогрессом и результатами.
4. При необходимости настройте и используйте хоткей Enqueue через Settings.

## Примечания

- После установки или обновления нужен полный рестарт WebUI. Одного Reload UI недостаточно.
- При старте в логе должна появиться строка `[AgentScheduler] NeverOOM/inference-tensor compat patched`.
- База очереди хранится в `task_scheduler.sqlite3`, если не задан `--agent-scheduler-sqlite-file`.
- Если часть живого состояния скриптов не попала в задачу, расширение использует DOM- и session-fallback для некоторых интеграций.
- Этот форк ориентирован на поведение Forge Neo / Gradio 4.

## Разработка

Главная Python-точка входа находится в `scripts/task_scheduler.py`. Логика фронтенд-моста лежит в `javascript/agent-scheduler.enqueue-bridge.js`, а код совместимости расширения — в `agent_scheduler/`.
